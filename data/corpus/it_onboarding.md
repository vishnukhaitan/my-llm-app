# IT onboarding

New joiners receive access in a fixed order. Do not skip steps.

## Day 0 (before start date)

IT ships a laptop to the address on file. Do not install unapproved browsers or browser extensions. FileVault / BitLocker must stay on.

## Day 1

1. Sign in with the welcome email from `it@northstar.example`.
2. Change the temporary password (16+ characters, password manager required).
3. Complete security training (45 minutes). Access to Git is blocked until the quiz is passed.
4. Join Slack workspaces `northstar-hq` and your team channel.

## Accounts

GitHub organization: `northstar-labs`. CI secrets are never stored in chat. The internal assistant is available at `https://assistant.northstar.internal/ask` after VPN is on.

## Hardware returns

When employment ends, return the laptop and badge within 5 working days. IT wipes the disk; do not reformat it yourself.
